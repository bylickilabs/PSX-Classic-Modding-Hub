# Sicherheitsrichtlinie

## Sicherheit hat Priorität

Der PSX Classic Modding Hub nimmt sicherheitsrelevante Meldungen ernst. Sicherheitslücken, unsichere Konfigurationen, offengelegte Zugangsdaten, schädliche Dateien oder andere sicherheitskritische Feststellungen dürfen **nicht** über ein öffentliches GitHub Issue, eine Discussion, einen Pull Request oder einen Kommentar gemeldet werden.

## Sicherheitsproblem melden

Bitte melde sicherheitsrelevante Probleme ausschließlich vertraulich per E-Mail an:

**bylicki@mail.de**

Verwende nach Möglichkeit einen eindeutigen Betreff, zum Beispiel:

`[PSX-Classic-Modding-Hub Sicherheit] Kurze Beschreibung`

## Benötigte Informationen

Bitte übermittle möglichst viele der folgenden Angaben:

- eine klare Beschreibung des Sicherheitsproblems
- die betroffene Datei, Konfiguration, den Workflow, Dokumentationsabschnitt oder die betroffene Repository-Komponente
- die betroffene Version, den Branch, Commit, die RetroArch-Version, den Core oder das PSX-Classic-Setup, sofern relevant
- reproduzierbare Schritte oder einen minimalen Proof of Concept
- das erwartete und das tatsächlich beobachtete Verhalten
- die mögliche Auswirkung des Problems
- relevante Logs, Screenshots, Hashwerte oder andere technische Nachweise
- bekannte Workarounds oder mögliche Gegenmaßnahmen

Übermittle keine Passwörter, Authentifizierungs-Tokens, privaten Schlüssel, personenbezogenen Daten, urheberrechtlich geschützten Spielinhalte, ROM-Abbilder, BIOS-Dateien oder andere Inhalte, zu deren Weitergabe du nicht berechtigt bist.

## Öffentliche Offenlegung

Bitte veröffentliche eine vermutete Sicherheitslücke nicht öffentlich, bevor sie geprüft wurde und gegebenenfalls geeignete Gegenmaßnahmen oder eine Korrektur vorbereitet wurden.

Öffentlich eingereichte Sicherheitsmeldungen können geschlossen, ausgeblendet oder aus der öffentlichen Diskussion entfernt werden, um eine unnötige Verbreitung sicherheitskritischer Informationen zu vermeiden. Die weitere Kommunikation soll anschließend ausschließlich über den privaten Meldeweg erfolgen.

## Geltungsbereich

Sicherheitsmeldungen können unter anderem folgende Bereiche betreffen:

- Repository-Dateien und Skripte
- GitHub Actions oder andere Automatisierungen
- Installations- oder Konfigurationsanleitungen, die ein Sicherheitsrisiko erzeugen
- unsichere Verarbeitung von Dateien, Pfaden, Berechtigungen oder externen Ressourcen
- schädliche oder unerwartet ausführbare Inhalte
- offengelegte Zugangsdaten, Tokens, Schlüssel oder andere sensible Informationen
- Abhängigkeits- oder Supply-Chain-Risiken, die den Inhalt des Repositorys direkt betreffen
- Konfigurationen, die erhebliche Sicherheitsauswirkungen auf die PlayStation Classic oder verbundene Systeme haben können

Allgemeine Fehler, Kompatibilitätsprobleme, Controller-Belegungen, Feature Requests, Hardware-Berichte und Dokumentationskorrekturen ohne Sicherheitsbezug sollen über das jeweils passende öffentliche Issue-Formular eingereicht werden.

## Unterstützter Stand

Die Sicherheitsprüfung konzentriert sich auf den aktuellen `main`-Branch und den neuesten Stand des Repositorys. Ältere Revisionen erhalten möglicherweise keine separaten Korrekturen, sofern das jeweilige Problem die aktuelle Version nicht ebenfalls betrifft.

## Koordinierte Bearbeitung

Gültige Meldungen werden anhand ihrer Reproduzierbarkeit, Schwere, betroffenen Komponenten und praktischen Auswirkungen bewertet. Wenn erforderlich, können Korrekturen oder Gegenmaßnahmen vorbereitet werden, bevor technische Details öffentlich gemacht werden.

Bitte handle verantwortungsvoll und unterlasse Aktivitäten, die Systeme beschädigen, Daten zerstören, andere Nutzer beeinträchtigen oder ohne ausdrückliche Berechtigung auf Systeme oder Informationen zugreifen könnten.

## Rechtmäßige und verantwortungsvolle Nutzung

Dieses Repository ist für legitimes PSX-Classic-Modding, Tests, Dokumentation, Interoperabilität und technische Forschung vorgesehen. Sicherheitstests dürfen ausschließlich an Systemen und Hardware durchgeführt werden, die dir gehören oder für deren Prüfung du ausdrücklich autorisiert wurdest.
