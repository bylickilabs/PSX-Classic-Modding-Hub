# Security Policy

## Security First

The PSX Classic Modding Hub takes security-related reports seriously. Security vulnerabilities, unsafe configurations, credential exposure, malicious files, or other security-sensitive findings must **not** be reported through a public GitHub Issue, Discussion, Pull Request, or comment.

## Reporting a Security Issue

Please report security-related issues privately by email:

**bylicki@mail.de**

Use a clear subject such as:

`[PSX-Classic-Modding-Hub Security] Short description`

## Information Required

Please include as much of the following information as possible:

- a clear description of the security issue
- the affected file, configuration, workflow, documentation section, or repository component
- the affected version, branch, commit, RetroArch version, Core, or PSX Classic setup where applicable
- reproducible steps or a minimal proof of concept
- expected behavior and actual behavior
- potential impact
- relevant logs, screenshots, hashes, or other technical evidence
- any known workaround or mitigation

Do not include passwords, authentication tokens, private keys, personal data, copyrighted game content, ROM images, BIOS files, or other material that you are not authorized to share.

## Public Disclosure

Please do not publicly disclose a suspected vulnerability before it has been reviewed and an appropriate mitigation or fix has been prepared where necessary.

Reports submitted publicly may be closed or removed from public discussion to reduce unnecessary exposure. Security details should then be continued through the private reporting channel.

## Scope

Security reports may include issues related to:

- repository files and scripts
- GitHub Actions or other automation
- installation or configuration instructions that create a security risk
- unsafe handling of files, paths, permissions, or external resources
- malicious or unexpectedly executable content
- exposed credentials, tokens, keys, or sensitive information
- dependency or supply-chain risks directly affecting repository content
- configurations that may create a material security impact on the PlayStation Classic or connected systems

General bugs, compatibility problems, controller mappings, feature requests, hardware reports, and documentation corrections that do not involve a security risk should use the appropriate public Issue Form instead.

## Supported Code

Security review is focused on the current `main` branch and the latest repository content. Older revisions may no longer receive fixes unless the same issue also affects the current version.

## Coordinated Handling

Valid reports will be assessed based on reproducibility, severity, affected scope, and practical impact. When appropriate, fixes or mitigations may be prepared before technical details are disclosed publicly.

Please act responsibly and avoid actions that could damage systems, destroy data, interfere with other users, or access systems or information without authorization.

## Legal and Responsible Use

This repository is intended for legitimate PSX Classic modding, testing, documentation, interoperability, and research. Security testing must be performed only on systems and hardware that you own or are explicitly authorized to test.
