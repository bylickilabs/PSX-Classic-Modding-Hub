# Mitwirken

> Beiträge zu weiteren getesteten Controllerprofilen sind willkommen.

## Anforderungen an neue Profile

> Bitte dokumentieren:
  - genaue RetroArch-Gerätebezeichnung
  - Vendor-ID und Product-ID in Dezimalform
  - VID:PID in Hexadezimalform, sofern bekannt
  - verwendeter RetroArch-Eingabetreiber
  - vollständige Tastenbelegung
  - getestetes System und Core
  - konkretes Spiel für den Funktionstest
  - bekannte Abweichungen oder Hardware-Revisionen

## Keine ungeprüften Profile

> Profile sollten nicht nur aus optisch ähnlichen Produkten oder Produktnamen abgeleitet werden. 
  - Bei günstigen USB-Controllern können verschiedene Chipsätze unter demselben Verkaufsnamen eingesetzt werden.

## Dateinamen

> Der Dateiname soll den tatsächlichen Gerätebezug nachvollziehbar machen. 
  - Für bestehende getestete Profile bleiben die im Repository verwendeten Namen aus Kompatibilitätsgründen erhalten.
